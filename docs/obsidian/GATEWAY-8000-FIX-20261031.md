## Compose change
```diff
-      - "127.0.0.1:8000:80"
+      - "127.0.0.1:8000:80"
+      - "192.168.1.136:8000:80"
```
Gateway container listens on port 80; host port 8000 therefore maps to container port 80 (not 8000). Kept loopback binding and added the verified LAN interface address rather than binding all interfaces.

- Attempted to narrow RemoteIP to `LocalSubnet,100.64.0.0/10`; Windows denied the change because the session is not elevated. The rule was not changed.
- Tailscale CLI is not installed and no 100.x IPv4 address is assigned on this SERVER. A Tailscale-IP health check could not be performed.
